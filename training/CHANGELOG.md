## Basic Submission Training

### v1 — draft (not yet effective)
- Change: initial curriculum (Getting Started + Basic Data Submission guide incl. Arcade walkthrough and video)
- Revised 2026-07-27 (folded into v1 draft — no attested users yet, so no version bump): upload-completion guidance added to the Basic Data Submission guide (keep AitriumOS open until the completion screen; post-upload verification on the trial page is now a required step; new troubleshooting entry for unregistered submissions) + "Critical behaviors" warning on the curriculum page. Would be a **material** change if the course were already effective (ref AIT-824). Because it is not, this revision reaches no one via re-attestation — affected sites must be notified directly.
- Revised 2026-10-29 (folded into v1 draft — no attested users yet, so no version bump): "Confirming your training" now directs users to confirm in the web portal (Trial Participation) instead of the AitriumOS prompt. Would be a **material** change if the course were already effective (the confirmation step moves to a different screen).
- Revised 2026-11-09 (no version bump, per Spencer's ruling 2026-11-09; statement unchanged, so the 51 existing confirmations stand): guides restructured for AitriumOS 2.3.4 (task-based EORTC data submission guide; shared Documents submissions, Multiple structure sets and Troubleshooting pages; What's new in 2.3). The curriculum is still Getting Started + the Basic Data Submission guide (EORTC data submission) + its walkthrough. The walkthrough is being re-recorded on 2.3.4 (script: `docs/eortc-walkthrough-script.md`); the 2.2-era video stays embedded until the new one replaces it. Sites already confirmed are told about 2.3 through the What's new page, not re-attestation.
