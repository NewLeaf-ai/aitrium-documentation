## Data Tools Module

The **Data Tools** module runs processing on your workstation, outside a trial submission. Filter the tools by category: **Analysis**, **De-identification**, or **Standardization**. Trial submissions run the same steps for you, so you don't need these tools to submit.

### De-identification

- **DICOM Metadata De-Identifier** de-identifies the DICOM metadata of the files you choose with a de-identification policy, and reports how many files it de-identified.
- **DICOM Metadata De-Identification Validator** checks files against a de-identification policy and reports anything that doesn't meet it.

<Warning>
  These tools de-identify DICOM metadata only. They don't remove patient information burned into image pixels, and they don't remove patient information from documents.
</Warning>

### Standardization

**RT Structure Standardizer** renames structures to standard structure names. Choose an output folder: the changed files are written there, and the original files are never changed.

<Warning>
  Always validate data after de-identification to check that the new files meet the trial's requirements.
</Warning>
